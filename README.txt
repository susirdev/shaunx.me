图库系统更新声明：如何添加照片

项目概述
本图库系统采用了动态加载机制，通过配置文件 asset_file.json 管理相册信息，并根据资产文件夹名称自动加载对应的图片文件。

添加照片步骤

1. 准备图片文件
   - 将您的照片按照数字顺序命名，例如：0.jpg、1.jpg、2.jpg、3.jpg...
   - 其中，0.jpg 将作为该相册的封面图片
   - 其他图片将按照数字顺序在相册中展示

2. 创建资产文件夹
   - 在 public/albums/ 目录下创建一个新的文件夹，用于存放您的照片
   - 文件夹名称应简洁明了，仅包含字母、数字和连字符（例如：mountain-sunrise、nanjizhilv）

3. 上传图片到资产文件夹
   - 将准备好的图片文件上传到刚创建的资产文件夹中
   - 确保图片文件名符合命名规则：0.jpg、1.jpg、2.jpg...

4. 更新配置文件
   - 打开 public/asset_file.json 文件
   - 在 albums 数组中添加一个新的相册配置对象，格式如下：
     {
       "title": "相册标题",
       "description": "相册描述",
       "asset_folder": "资产文件夹名称"
     }

5. 重启开发服务器（仅开发环境）
   - 如果您正在本地开发，需要重启开发服务器以加载新的配置
   - 运行命令：npm run dev

详细说明

图片命名规则
- 封面图片：必须命名为 0.jpg，将作为相册的封面展示
- 其他图片：按照数字顺序命名，例如：1.jpg、2.jpg、3.jpg...
- 图片格式：支持常见的图片格式，如 .jpg、.jpeg、.png、.webp 等
- 图片尺寸：建议图片宽度不超过 2000px，以保证加载速度

配置文件 asset_file.json 说明
- title：相册的显示标题（例如："南极之旅"）
- description：相册的描述文字（例如："探索南极的壮丽景色"）
- asset_folder：资产文件夹名称，必须与 public/albums/ 下的文件夹名称完全一致（例如：nanjizhilv）

示例

示例 1：添加"南极之旅"相册
1. 在 public/albums/ 目录下创建 nanjizhilv 文件夹
2. 将照片上传到该文件夹，命名为：0.jpg、1.jpg、2.jpg、3.jpg...
3. 在 asset_file.json 中添加：
   {
     "title": "南极之旅",
     "description": "探索南极的壮丽景色",
     "asset_folder": "nanjizhilv"
   }

示例 2：添加"城市夜景"相册
1. 在 public/albums/ 目录下创建 city-night 文件夹
2. 将照片上传到该文件夹，命名为：0.jpg、1.jpg、2.jpg...
3. 在 asset_file.json 中添加：
   {
     "title": "城市夜景",
     "description": "城市夜景的魅力",
     "asset_folder": "city-night"
   }

常见问题

Q: 为什么我的相册没有显示？
A: 请检查以下几点：
1. asset_file.json 中的 asset_folder 名称是否与实际文件夹名称一致
2. 文件夹是否位于 public/albums/ 目录下
3. 文件夹中是否包含 0.jpg 作为封面图片
4. 开发服务器是否已重启（仅开发环境）

Q: 我可以使用其他图片格式吗？
A: 可以，支持 .jpg、.jpeg、.png、.webp 等常见图片格式。

Q: 相册中的图片顺序可以调整吗？
A: 可以，通过修改图片文件名的数字序号来调整顺序。

Q: 我可以添加多少张图片到一个相册？
A: 理论上没有限制，但建议每个相册不超过 50 张图片，以保证良好的加载速度。
